- **Q1.** Is the Primary Action (what to reveal / hold back now) reasonable for this draft state?
- **Q2.** Is the position the Coach tells the Player to reveal (or defer) reasonable — is it the right role to show first / hold?
- **Q3.** Are the shortlist heroes plausible for that role in this state? Name any that are not.
- **Q4.** Is the personal-position ranking ("TU … AHORA") useful for a player of that position, and is the Hero Pool marker ("Tu pool") used sensibly?
- **Q5.** Is Flex uncertainty ("FLEX x/y" for own heroes, "Likely Pos… / Possible Pos…" for enemy heroes) represented honestly — neither over-claimed nor over-hedged?
- **Q6.** If a "Ventana de core" (Safe Core) block is shown, is it warranted by the state? If it is absent, should it have been shown?
- **Q7.** Is any IMPORTANT visible counter, synergy or draft-shape consideration missing from the advice?
- **Q8.** Is any part of the advice overconfident given the evidence stated in it?
- **Q9.** Comparing the decision points: does the advice react sensibly to the Player's pick and to newly revealed information?
- **Q10.** Overall: would this advice help a serious Ranked player make the decision at this point? (1 = harmful, 3 = neutral, 5 = clearly helpful)
