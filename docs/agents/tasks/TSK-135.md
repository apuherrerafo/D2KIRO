## Qué mide

Para una muestra de al menos **50** drafts del corpus (`knn/pro-draft-corpus.json`, **502** drafts
reales, **124** héroes distintos — corrige la cabecera desactualizada del script, que dice "~175"),
genera **2 variantes de conjunto de bans** por draft (16 héroes cada una, muestreadas del propio
corpus, semilla fija y declarada para reproducibilidad). Para cada variante calcula el top-5 de
apertura por los dos caminos:

- **V5**: `buildSuggestions(state, meta, { teamOpening: true })` → `recommendTeamOpeners`.
- **Pro-Drafter**: `runProDrafterPipeline(..., { teamOpening: true, matchups, heroCapabilities })`.

**Métrica**: índice de Jaccard del top-5 entre las dos variantes de ban del mismo draft
(`|A∩B|/|A∪B|`, más bajo = más sensible). Reporta la media por camino, más el número de héroes
distintos (de 5) y el porcentaje de casos en que cambia el rank 1 — las tres, no solo la primera:
un Jaccard bajo con el rank 1 fijo no resuelve la queja tal como el usuario la formuló ("las mismas
sugerencias primarias").

## Barra de aceptación (cerrada en el blueprint, las tres condiciones)

1. Jaccard medio del top-5 de Pro-Drafter **≤ 0.35**. Referencia simulada: `0.225`.
2. Jaccard medio de Pro-Drafter **estrictamente menor** que el de V5 sobre la misma muestra, con
   diferencia absoluta de al menos **0.15**.
3. El héroe de rank 1 cambia en al menos el **60%** de los pares de variantes. Referencia
   simulada: `89.0%`.

## Qué NO decide este script
No prende `ENABLE_PRO_DRAFTER`, no retira `MAX_COUNTER_RELIEF`, no promueve nada. Es el insumo de
un **segundo `/blueprint`, más angosto**, que decidirá entre: (a) prender el flag solo para el caso
de apertura, (b) portar únicamente el término ban-aware a `team-opener.ts` sin adoptar el resto de
Pro-Drafter, o (c) dejarlo dark y curar más datos. Las tres siguen siendo posibles al terminar esta
fase.

## Criterios de aceptación
- El script corre con una semilla fija declarada — dos corridas producen el mismo resultado.
- Reporta las tres métricas (Jaccard medio, héroes distintos, % de cambio de rank 1) para ambos
  caminos, no solo uno.
- La cabecera del script se actualiza para decir "502 drafts / 124 héroes", no "~175".
