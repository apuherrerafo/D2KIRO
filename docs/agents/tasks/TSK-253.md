## Contexto

Decisión del propietario: D2Kiro usa sólo sus agentes, skills, workflows y reglas; las versiones globales no
deben sustituir a las del repo. Hallazgo (reproducido con el binario real de Claude Code 2.1.329): los 25
skills del repo existen también en `~/.claude/skills/` y, por precedencia documentada
(`enterprise > personal > project`), gana la copia personal. `dispatch`, `root-cause` (y el agente
`chronicle`) son versiones **viejas** respecto del repo.

## Criterio de aceptación

- Detector puro de skills del repo sombreados por la copia personal, con prueba (ignora `.trash` y
  skills sólo-personales).
- Lanzador `claude --setting-sources project,local` verificable sin red.
- Doc con matriz por proveedor y limitaciones. No se toca ninguna configuración global.
