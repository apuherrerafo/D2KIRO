- La base `PHASE_FALLBACK` viaja a V4 como `DETERMINISTIC_DEFAULT` (el cable de V4 no tiene `PHASE_FALLBACK`): sigue diciendo "no hay prioridad estratégica clara". Sólo `COUNTER_WINDOW` / `POOL_SCARCITY` salen `STRATEGIC`.
- Nada se oculta: toda columna abierta sigue rankeada y seleccionable; la prioridad sólo elige a cuál mirar primero.
- No se tocó puntuación, pesos, `signals/`, ni el cable web (sólo un comentario de tipos).
