Reemplazar el límite numérico obsoleto de validación por un snapshot explícito del catálogo
oficial de OpenDota. La lista conserva los huecos de IDs de Valve y permite héroes nuevos como
136 y 155 sin aceptar valores inventados.

## Cierre

`validateDraftShape` valida contra 127 IDs curados de `/api/heroes` (consulta 2026-08-27). Se
añadieron regresiones para aceptar el ID 155 y rechazar el hueco 127. El snapshot es offline y
determinista; una futura actualización de catálogo debe ser un cambio explícito y revisable.
