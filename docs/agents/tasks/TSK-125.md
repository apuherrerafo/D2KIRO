## Contexto

Al intentar commitear TSK-124, el hook `PostToolUse`/`PreToolUse` de Claude Code (que corre
`scripts/verify-simplicity.sh`, y este a su vez la suite completa) bloqueó el commit con un error
real: `Failed to register. Happy DOM has already been globally registered.` en
`use-random-draft-session.integration.test.ts` (TSK-117).

Causa: `CopilotPanel.test.tsx` (nuevo, llegó junto con TSK-123 en paralelo) también llama
`GlobalRegistrator.register()` en su propio archivo -- `bun test` corre ambos archivos en el mismo
proceso, y `GlobalRegistrator` es un singleton de módulo que lanza si se registra dos veces. Antes
de TSK-123 solo existía un archivo que necesitaba DOM real; con dos, el diseño original (cada
archivo se registra a sí mismo) dejó de sostenerse.

## Cambio

Nuevo `apps/web/test-support/happy-dom.ts`: registra una sola vez, guardado por
`GlobalRegistrator.isRegistered` (getter real de la librería, verificado antes de asumir que
existía). Los dos archivos de prueba pasan de `GlobalRegistrator.register()` inline a
`import "@/test-support/happy-dom";` -- el cacheo de módulos de Bun garantiza que el registro real
solo corre una vez sin importar cuántos archivos lo importen.
