## Contexto

Rama `ux/landing-memory-strip`, continúa `TSK-241` (congelada: Hero → Memory → Player Model). Siguiente bloque
narrativo de la landing real: **qué cambia porque D2KIRO me conoce**. Un solo objeto de draft/recomendación que
existe primero en lectura genérica ("Generic meta") y sobre el que actúa el Player Model: la evidencia se

Entra: sección `CounterfactualSection` pegada al final del Memory Strip, fixture cualitativo (sin cifras
inventadas), modelo puro ranking + timeline de scroll, movimiento por variables CSS escrutadas por scroll
(reorden FLIP-like sin librería), reduced motion por estados discretos, costura Coach (`counterfactual`),
historia de Storybook y pruebas de invariantes de producto.

personaje Coach, CTA/footer, backend, datos Dota reales, servicio de Generic Meta, ML.

## Resultado (2026-10-07) — listo para revisión de producto

- **Concepto**: un solo objeto (draft + ranking de tres héroes en slots fijos + el Player Model como entrada). Se lee primero
  como "Generic meta" y después a través del modelo; el orden se DERIVA (`counterfactual/model.ts`), nunca se almacena.
  Outworld Destroyer (genérico #1) y Puck (genérico #2) se intercambian; Ember Spirit no cambia. Causa explícita en Puck:
  `Lane · qualified` (la lectura de Viper con sus partidas) + `History · yours`. Sin cifras: niveles cualitativos 0–3.
- **Movimiento**: tres variables CSS (`--cf-ctx`, `--cf-rein`, `--cf-p`) escrutadas por scroll; reorden = transform entre slots
  (el que sube se levanta y pasa por encima). Sin librería. Reduced motion: variables 0/1, estados discretos + fade corto.
- **Scroll**: pin corto de 2,2 pantallas (Memory: 5,05). Handoff: el contorno del Player Model vuelve grande y se comprime
  en la ficha "Your player model".
- **Coach**: placement `counterfactual` + `counterfactualCoachCue(stage)`. Sin personaje.
- Evidencia: `docs/diagnostics/counterfactual/` (hojas por viewport, reduced, WebM, `report.json`, `capture.mjs`).
