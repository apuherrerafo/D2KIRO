## Objetivo

Mostrar el momento real de All Pick y separar los motivos positivos de los riesgos del Copilot,
sin parsear la explicación textual del motor.

## Alcance

- `SuggestionSet` expone `decisionContext` estructurado y la apertura agrega evidencia `opening`.
- Copilot V5 muestra una cabecera para apertura, Pick 2 ciego, Pick 3/4 y cierre.
- `SuggestionCard` agrupa motivos y riesgos/incertidumbres en secciones distintas.
- Se prueban el contrato engine ↔ web y el render de las cuatro fases.
