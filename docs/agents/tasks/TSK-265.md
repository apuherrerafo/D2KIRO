## Contexto

La revisión externa de `5e78243b` rechazó el PR por dos defectos: una ficha con `"write_scope":` o `write_scope :` se
aceptaba como válida y quedaba sin alcance; y un cambio formado sólo por archivos sin seguimiento llegaba con los
diffs vacíos, que los revisores no pueden aprobar.

## Criterio de aceptación

- Una declaración de `write_scope` malformada, ambigua o repetida bloquea la escritura; las fichas válidas siguen igual.
- El paquete de evidencia entrega el contenido de los archivos nuevos; un cambio así puede aprobarse.
- Diff vacío o contenido no recibido: nunca se aprueba.
- Prueba roja antes y verde después de cada defecto.
