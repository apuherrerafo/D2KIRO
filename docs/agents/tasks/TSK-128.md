```ts
// Mismo valor y misma razón que signals/counter.ts y drafter/team-opener.ts, declarado local --

export const MIN_MATCHUP_GAMES = 200;

export type MatchupWinrateFn = (
  candidate: HeroId,
  rival: HeroId,
  position: 1 | 2 | 3 | 4 | 5,
) => number | null;

export function createMetaMatchupWinrate(
  matchups: Record<HeroId, HeroMatchupStat[]>,

```

Contrato exacto:
1. Construye un índice `Map<HeroId, Map<HeroId, HeroMatchupStat>>` **una vez** al crear la función
   (no un `.find` por llamada — se invoca 5 veces por par candidato/rival, ~110 candidatos).
2. Fila ausente → `null`.
3. `row.games < MIN_MATCHUP_GAMES` → `null` (nunca `0` — regla dura de `engine.md`, `raw: null`
   nunca se disfraza).
4. En otro caso → `row.wins / row.games`, en `[0, 1]`.
5. `position` se ignora por completo (parámetro `_position`) — `hero_matchups` no tiene columna de
   posición, hueco heredado ya documentado en `denial-score.ts`. Se conserva el parámetro porque la
   firma de `calculateDenialScore` lo exige.

## Criterios de aceptación

- Par ausente en el índice → `null`.
- Par con `games < 200` → `null`, nunca `0`.
- Par con `games >= 200` → `wins/games` exacto.
- El índice se construye una sola vez por llamada a `createMetaMatchupWinrate` — verificar con un
  test que cuenta invocaciones si es necesario, no reconstruir por cada consulta.
