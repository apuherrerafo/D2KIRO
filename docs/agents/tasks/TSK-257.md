## Contexto

`scripts/agents/contracts.ts` declara `READ_ONLY_AGENTS = [sentinel, tracer, warden]` pero sólo comprueba que su `tools:`
no incluya Write/Edit/MultiEdit/NotebookEdit. Los tres declaran `Bash`, y con Bash se escribe igual (`echo x > f`,
`sed -i`, `git checkout -- .`, `python3 -c`). "Solo lectura" estaba garantizado únicamente por su Markdown.

## Reproducción (rojo)

Cadena PreToolUse anterior (`pretooluse-guard.sh` de `21c05e22`) con payload de subagente `agent_type: warden`:
`echo x > f.txt` → exit 0; `sed -i s/a/b/ README.md` → exit 0; `git checkout -- .` → exit 0 (los tres permitidos).

## Solución

`readonly-agent-guard.py`, encadenado dentro de `pretooluse-guard.sh` (misma entrada que ya tenía el matcher
`Bash|PowerShell`; sin hook nuevo en `settings.json`). Decide por `agent_type` del payload (Claude Code 2.1.329 lo
incluye en todo PreToolUse de un subagente; verificado en el esquema del binario instalado). Lista BLANCA: sólo cadenas
de comandos simples (`|`, `&&`, `||`) de lectura; todo lo demás se bloquea. Fallo cerrado ante payload ilegible,
`agent_type` no textual o subagente sin `agent_type`. Una prueba exige que su lista coincida con `READ_ONLY_AGENTS`.

## Estado
