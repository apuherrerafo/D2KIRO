## Objetivo

Ampliar la cobertura de matchups válidos para que la sensibilidad de apertura pueda superar la
barra de TSK-135 sin sobreajustar `BETA_OPENING` sobre un corpus escaso.

## Alcance

- Evaluar una fuente de datos ampliada (dataset local o ingestión vía Explorer) manteniendo el
  contrato `HeroMatchupStat` y el umbral de calidad documentado.
- Incorporar una muestra reproducible al benchmark `--ban-sensitivity` y reportar cobertura,
  Jaccard y cambio de rank 1.
- Mantener `ENABLE_PRO_DRAFTER` apagado hasta que la barra de TSK-135 se cumpla con datos válidos.

## Fuera de alcance

No cambiar más perillas de scoring ni rebajar silenciosamente `MIN_MATCHUP_GAMES`.

## Implementación y resultado (2026-08-26)

- Se añadió `scripts/fetch-expanded-matchups.ts`, que pagina lotes de 1.000 partidas de alto MMR
  mediante OpenDota Explorer, agrega pares localmente y conserva `MIN_MATCHUP_GAMES = 200`.
- La escritura en SQLite es opt-in (`--write-db`) y realiza upsert parametrizado sobre
  `hero_matchups`; nunca reemplaza el catálogo con un snapshot vacío.
- La ejecución reproducible de 10 lotes produjo 104 pares válidos. El benchmark de apertura se
  ejecutará con este snapshot antes de activar `ENABLE_PRO_DRAFTER`.
