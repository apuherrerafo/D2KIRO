## Contrato de señal (S3) — todas las señales tienen esta forma exacta, sin excepciones
```ts
type SignalId = 'counter' | 'patch_meta' | 'team_synergy' | 'role_gap';

interface SignalContribution {
  signal: SignalId;
  raw: number | null;      // null = sin datos suficientes. NO es 0, NO es 0.5.
  weighted: number;
  explanation: string;     // frase corta, en español, mostrable tal cual
  sampleSize: number;      // partidas detrás del dato; 0 en señales heurísticas
}

interface SignalScorer {
  id: SignalId;
  score(state: DraftState, candidate: HeroId, meta: MetaSnapshot): SignalContribution;
}
```

## Especificación de `counter` (peso v1: **0.40**)
- Fuente: real — OpenDota `/heroes/{id}/matchups`.
- Cálculo: para cada héroe enemigo ya elegido (`state.picks` del lado contrario a
  `state.localSide`), el winrate del candidato contra él **menos** su winrate base. Se promedia
  sobre los enemigos conocidos.
- **Umbral**: un enfrentamiento con menos de **200 partidas** no cuenta para el promedio.
- Si no hay ningún enfrentamiento válido (0 enemigos conocidos, o todos por debajo del umbral) →
  `raw: null`, `sampleSize: 0`.
- `explanation`: frase corta y concreta, ej. "Fuerte contra Lina y Zeus" — nombra los héroes
  enemigos contra los que el candidato rinde mejor, no un texto genérico.

## Reglas duras (aplican a todo `SignalScorer`, no solo a este)
- Función pura: misma entrada, misma salida. Sin I/O.
- Si el scorer lanzara una excepción en producción, el motor lo trata como `raw: null` — pero la
  responsabilidad de este ticket es que la función **nunca lance** en primer lugar para entradas
  válidas.
- `raw: null` nunca se convierte en `0` en `weighted` de forma silenciosa — el motor (ticket
  aparte) es quien redistribuye el peso; aquí solo se devuelve `null` cuando corresponde.

## Aceptación
- Prueba con 0 enemigos conocidos → `raw: null`.
- Prueba con enemigos conocidos pero todos bajo 200 partidas → `raw: null`.
- Prueba con al menos un enfrentamiento válido → `raw` numérico, `sampleSize` correcto,
  `explanation` menciona los héroes relevantes.
