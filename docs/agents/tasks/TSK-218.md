## Contexto

`CLAUDE.md` + `.claude/rules/**` suman **~1.970 líneas que se inyectan en cada turno**. La mayoría
describe fases cerradas (1, 1b, 3, 4, 4.1, 4.2, 4.3, 5, 6, 8). El consejo de "darle a Claude
instrucciones persistentes" está bien, pero llevado a este extremo se invierte: la regla viva queda
enterrada bajo narrativa histórica, y es causa directa de que se repitan discusiones ya cerradas.

Dato concreto de esta misma sesión: `CLAUDE.md` documenta `bun test` como el comando de pruebas.
Ese comando da **~55 fallos falsos** (`@happy-dom/global-registrator` parchea el `fetch` global y
contamina los tests de servidor del motor). Por raíz separada son 617 + 215 + 177, cero fallos —
que es lo que ya hacen CI y `verify-simplicity.sh`. Una instrucción equivocada le costó tiempo real
a esta sesión, y se lo costaría a cualquier otra.

## Alcance

1. **Archivar los 9 resúmenes de fase cerrada** (`fase-1`, `1b`, `3`, `4`, `4.2`, `4.3`, `5`, `6`,
   `8`) a `docs/rules-archive/`. **No se pierde nada vinculante**: cada uno de esos archivos dice
   de sí mismo que es un resumen de lo que vive en `engine.md`/`web.md`/`security.md`/
   `testing-seams.md`, que siguen cargándose enteros.
2. **`.claude/rules/invariantes.md`** (nuevo, corto): las reglas que son verdad en toda fase, para
   que estén al frente y no haya que deducirlas de 10 narrativas.
3. **`CLAUDE.md`**: corregir el comando de pruebas y apuntar a las reglas que quedan.
4. **`package.json`**: script `test` de raíz que corre las tres raíces por separado — que el
   comando correcto sea el más fácil de escribir.
5. **`verify-claude-md-split.sh`**: concatenar también `docs/rules-archive/fase-*.md`, para que la
   garantía de "el split no perdió una línea" siga siendo verificable tras el movimiento.

## Criterios de aceptación

1. `bash scripts/verify-claude-md-split.sh` → OK (ninguna línea perdida, `CLAUDE.md` < 200 líneas).
2. `bun run test` corre las tres raíces y da 617 + 215 + 177, cero fallos.
3. `bash scripts/verify-simplicity.sh` verde.

## Fuera de alcance (declarado, no olvidado)

Las secciones por fase **dentro** de `engine.md`/`web.md`/`security.md`/`testing-seams.md` (1.351
líneas, 9-11 secciones por archivo). Ahí está el grueso real, pero destilarlas exige revisar regla
por regla cuáles siguen siendo vinculantes; hacerlo rápido es la forma más segura de perder un
invariante. Ticket aparte, con revisión humana.
