## Forma exacta de MetaSnapshot a producir (definida en `apps/engine/src/signals/types.ts`, no se repite aquí — importarla, no reinventarla)
```ts
interface MetaHeroInfo { id: HeroId; localizedName: string; roles?: string[] }
interface HeroMatchupStat { vsHero: HeroId; games: number; wins: number }
interface HeroPatchBracketStat { patch: string; bracket: Bracket; picks: number; wins: number }
interface MetaSnapshot {
  heroes: Record<HeroId, MetaHeroInfo>;
  matchups: Record<HeroId, HeroMatchupStat[]>;
  patchStats?: Record<HeroId, HeroPatchBracketStat[]>;
}
```
`Bracket` vive en `apps/engine/src/meta/mappers.ts` (ya existe, TSK-003).

## Qué construir
1. **`buildMetaSnapshot(db): Promise<MetaSnapshot>`** en `apps/engine/src/meta/provider.ts` (o
   nombre equivalente) — 3 queries masivas vía Drizzle (nunca N+1 por héroe, el motor recorre
   candidatos en su camino caliente y no puede esperar una query por héroe):
   - `db.select().from(heroes)` → arma `heroes: Record<HeroId, MetaHeroInfo>` (incluye `roles`,
     ya es JSON parseado por Drizzle desde TSK-002).
   - `db.select().from(heroMatchups)` → agrupa por `heroId` en `matchups`.
   - `db.select().from(heroPatchStats)` → agrupa por `heroId` en `patchStats`.
2. **`getMetaFreshness(db, now?): Promise<{ syncedAt: string | null; isStale: boolean }>`** —
   lee la fila más reciente de `meta_sync` con `status: 'ok'`. Ventana de frescura: **24 horas**
   (`docs/specs/SPEC.md` línea 329). Sin ninguna sincronización exitosa todavía → `syncedAt: null,
   isStale: true` (cache vacío en el primer arranque es un estado legítimo, no un error).

## Reglas duras
- Cero SQL concatenado — todo vía Drizzle (`db.select().from(...)`), consistente con TSK-002.
- Cero llamada a OpenDota aquí — este puente solo LEE SQLite. La sincronización ya es
  responsabilidad de `syncMeta` (TSK-003); este ticket no la toca ni la duplica.
- `buildMetaSnapshot` no debe hacer una query por héroe dentro de un loop (regla de Standards de
  `@redteam`, N+1 de Drizzle) — 3 queries totales, sin importar cuántos héroes haya.
- Cache vacío (ninguna tabla poblada todavía) → `MetaSnapshot` con los 3 records vacíos, nunca
  una excepción — es exactamente el escenario de "primer arranque" que TSK-009 ya sabe degradar
  a heurísticas + `confidence: 'baja'`.
