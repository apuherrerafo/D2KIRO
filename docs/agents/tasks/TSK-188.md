## Contexto

Tras el QA de 8A, el usuario pidió una señal nueva y coherente: **"tus counters están baneados =
pick más libre"**. Ejemplo suyo: considerás Morphling (id 10 — countereado por Silencer 75 hard,
AA 68 medium, Clockwerk 51 medium en `hero-counters.json`); ves que Silencer está baneado → el
Copilot lo marca a favor y explica por qué. Si **ningún** counter suyo está baneado → no suma
nada (nunca penaliza). Contrato cerrado en `SPEC.md` §14.13, reglas en `.claude/rules/engine.md`
("Fase 8 addendum"). Follow-up aditivo de `TSK-185`/`TSK-186`; entra en el mismo push que Fase 8.

Decisiones del usuario (`AskUserQuestion`, 2026-08-28): **construir ahora, antes del push**; el
bono **vota desde el pick 1** (no necesita enemigos revelados).

## Alcance — solo `apps/engine/src/signals/counter.ts` + `counter.test.ts`

1. **Constantes** (`counter.ts`, valores de arranque QA-tuneables):
   ```typescript
   const BAN_RELIEF: Record<"hard" | "medium", number> = { hard: 0.04, medium: 0.02 };
   const BAN_RELIEF_CAP = 0.06; // la mitad de M.hard
   ```
2. **`score(state, candidate, meta)`** dentro de `createCounterScorer`:
   - `banned = observedDraftFacts(state).bannedHeroes` (ya existe, se devuelve incluso con
     `localSide: "unknown"`).
   - `banReliefEntries = (curated.get(candidate) ?? []).filter((e) => banned.includes(e.vs))`.
   - `banRelief = min(BAN_RELIEF_CAP, Σ BAN_RELIEF[e.level])` sobre esas entradas. Nombres de
     `meta.heroes[e.vs]?.localizedName` para la explicación (hasta 2).
   - `meanRevealed = contribs.length > 0 ? mean(contribs) : 0` (el `mean(c_r)` de 8A).
   - **`raw: null` sii** `contribs.length === 0` **y** `banRelief === 0` (idéntico a hoy en ese
     caso). Si no:
     - `banRelief === 0` → `raw = meanRevealed` **sin clamp** (8A byte-idéntico; el candado de
       §14.7 tiene un fixture que da `0.12222 > M.hard` y debe seguir dándolo).
     - `banRelief > 0` → `raw = clamp(meanRevealed + banRelief, -M.hard, M.hard)`.
   - `sampleSize` = Σ games de la capa estadística **solo** (el alivio no aporta, igual que la
     capa curada).
   - `explanation`:
     - hubo rival revelado (curada o estadística) **y** alivio → `"<texto de 8A>. <N> de sus
       counters están baneados: <nombres>"`.
     - solo alivio → `"<N> de sus counters están baneados: <nombres>"`. (singular "1 de sus
       counters está baneado: X" cuando N === 1).
     - solo rival revelado → el texto de 8A, sin cambios.
3. **`counter.test.ts`** — casos nuevos:
   - pick 1, sin enemigos revelados, con Silencer (75) baneado y candidato Morphling (10) curado
     `{vs:75, hard}` → `raw ≈ +0.04`, explanation cita Silencer, `sampleSize: 0`.
   - dos counters baneados (hard + medium) → `raw ≈ +0.06` (topa `BAN_RELIEF_CAP`), explanation con 2 nombres.
   - ningún counter del candidato baneado → `raw: null` (sin cambios), no lanza.
   - rival revelado que te counterea (hard, `-0.12`) + un counter tuyo baneado (`+0.04`) →
     `raw ≈ -0.08`, explanation anexa la cláusula de bans al `why` de 8A.
   - **candado de regresión §14.7 intacto**: `createCounterScorer(new Map(), { minGames: 200,
     shrinkPriorStrength: null })` con héroes baneados en el state → `banRelief` sigue 0 (mapa
     vacío) → mismo `raw`/`explanation`/`sampleSize` que hoy. Reafirmar en el test existente o
     uno nuevo.
   - Fixtures inline, jamás `hero-counters.json` real (S9).
