## Contexto

SPEC.md §16.5. El generador de los percentiles empíricos que reemplazan la normalización lineal de
`RAW_RANGE`. Se calculan sobre los folds de **train** (nunca el held-out) del `split.json` de 9.0,
sobre el perfil YA arreglado por TSK-207 (`patch_meta` votando).

## Alcance

- **`scripts/stats/build-percentiles.ts`** — función pura `computePercentiles(rawsBySignal,
  splitFolds): PercentilesFile` + un `main()` que abre `dota2coach.sqlite` y `pro-drafts.sqlite`
  **`readonly`**, reconstruye los `ReplayCase` de los folds de train (con el `patchOverride` de
  TSK-207), corre los 6 scorers (mismos building blocks que `profile-signals.ts`), junta los `raw`
  **no nulos** por señal, y calcula `p05`/`p95` por señal (`global`) y por bracket del estado
  (`byBracket`) si `n ≥ 200`.
- Formato de `data/generated/percentiles.json` (§16.5):
  ```
  { "schemaVersion": 1, "trainSplitHash": string, "corpusPatchOverride": string,
    "signals": { "<SignalId>": { "global": {"p05","p95","n"}, "byBracket"?: {...} } } }
  ```
- **Señales `applicable:false` estructural en el backtest** (`hero_pool_fit`, `archetype_fit`) →
  `null` en el JSON (el motor usa su `RAW_RANGE` `[0,1]`, que ya es correcto: el `raw` viene
  normalizado de adentro del scorer).
- `data/metadata/percentiles.json` con procedencia (§15.4.1).
- **Congelado**: se genera una vez, se versiona. No se regenera salvo re-etiquetado de datos o
  patch nuevo (mismo criterio que `split.json`).

## Criterios de aceptación

1. `build-percentiles.test.ts`: `computePercentiles` sobre un fixture literal de `raw` por señal
   devuelve `p05 < p95` para las señales con datos; una señal sin datos → `null`.
2. `bun run scripts/stats/build-percentiles.ts` real → `percentiles.json` con `counter.global`
   cerca de `[−0.044, +0.052]` (± tolerancia de muestreo), `position_fit.global` cerca de
   `[0, 1]`, `team_synergy.global` cerca de `[0, 0.29]`, `patch_meta.global` con `n > 0`,
   `hero_pool_fit`/`archetype_fit` = `null`.
3. `trainSplitHash` coincide con el `splitHash` del `split.json` (train = folds != held-out).
4. Determinismo: dos corridas → `percentiles.json` byte-idéntico.
5. `git diff --name-only` no toca `apps/`. `(cd scripts && bun test)` verde.
