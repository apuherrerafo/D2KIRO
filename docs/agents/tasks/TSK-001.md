## Qué construir
- Instalar Bun (prerrequisito, confirmar versión).
- `apps/engine/`: proyecto Bun mínimo (package.json, tsconfig estricto, punto de entrada que
  arranca un servidor HTTP en `127.0.0.1` y responde `GET /api/health`).
- `apps/web/`: proyecto Next.js (App Router, TypeScript estricto, Tailwind + shadcn/ui) mínimo,
  sin páginas todavía más allá de un placeholder.
- Estructura de carpetas preparada para arquitectura por features en `apps/web` (ver
  `.claude/rules/web.md`).
- `bun test` corriendo (aunque sea con una prueba trivial) en `apps/engine`.

## No hacer aquí
