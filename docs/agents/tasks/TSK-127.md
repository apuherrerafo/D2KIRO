```ts
import type { PipelineWeights } from "./weight-loader";

// Misma frontera que deriveDecisionContext usa para declarar terminada la fase ciega
// (enemy>=2 && own>=2 -> "response_pick"). No es un número nuevo, es el gate discreto que el
// proyecto ya tiene, leído como frontera continua.
export const OPENING_SPAN = 4;

export function openingBlend(ownPickCount: number, enemyPickCount: number): number {
  const confirmed = ownPickCount + enemyPickCount;
  return Math.max(0, 1 - confirmed / OPENING_SPAN);
}

export function deriveContinuousPipelineWeights(
  base: PipelineWeights,
  ownPickCount: number,
  enemyPickCount: number,
): PipelineWeights {
  const t = openingBlend(ownPickCount, enemyPickCount);
  const knnSimilarity = base.knn_similarity * (1 - t);
  const laneScore = base.lane_score; // no depende de picks
  const denialScore = 1 - knnSimilarity - laneScore; // por RESTA, nunca sumando el sobrante
  return { knn_similarity: knnSimilarity, lane_score: laneScore, denial_score: denialScore };
}
```

## Por qué `denial_score` sale por resta, no por suma
Sumar el peso liberado (`base.denial_score + base.knn_similarity * t`) da el mismo número en
aritmética exacta, pero acumula error de punto flotante en dos operaciones distintas. Derivar el
tercero por resta hace que la suma sea 1.0 por construcción, no por casualidad numérica.

## Criterios de aceptación (SPEC §13.14, criterio 7)

- `|knn_similarity + lane_score + denial_score − 1| ≤ SUM_EPSILON` para **toda** combinación de
  `(ownPickCount, enemyPickCount)` en `0..5 × 0..5` — mismo `SUM_EPSILON` exacto que ya usa
  `parsePipelineWeights` en `weight-loader.ts` (`1e-9`). Nunca comparar con `=== 1`.
- Con `base = pro-drafter-weights-v6.json` (`0.40/0.35/0.25`), verificar la tabla exacta:
  `own+enemy=0 → 0.00/0.35/0.65`; `=1 → 0.10/0.35/0.55`; `=2 → 0.20/0.35/0.45`;
  `=3 → 0.30/0.35/0.35`; `≥4 → 0.40/0.35/0.25` (== `base` exacto).
- Con `own+enemy >= 4`, `deriveContinuousPipelineWeights` devuelve **exactamente** `base` — el
  camino normal en fase media/tardía no cambia en nada.
