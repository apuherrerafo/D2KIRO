## Contexto (ticket autocontenido)
Proyecto: dota2coach. Pedido en vivo del usuario, mid-QA: "si me estás dando señales, mínimo
dejame escoger alguno de esos" -- hoy, para pickear el héroe que el propio Copilot está
sugiriendo, hay que volver a abrir "Entrada manual" y buscarlo de nuevo en la lista completa de
héroes. Fricción innecesaria para el caso más común (aceptar la sugerencia).

## Alcance
### 1. `apps/web/components/suggestion-card/SuggestionCard.tsx`
Gana un prop opcional `onPick?: (hero: HeroId) => void`. Cuando está presente, muestra un botón
"Pickear" (estilo `BUTTON_PRIMARY` si `isPrimary`, `BUTTON_SECONDARY` si no) que llama a
`onPick(suggestion.hero)` -- manejador nombrado, no inline. `undefined` = no se muestra el botón
(uso en pruebas aisladas, o si no hay lado propio identificado).

### 2. `apps/web/features/draft/DraftView.tsx`
`ActiveDraftState` gana `handleQuickPick(hero)`: manda `hero_picked` vía `postManualEvent`
(mismo mecanismo que `ManualEntryPanel`) con `side: draftState.localSide`. Si `localSide ===
"unknown"`, no se pasa `onPick` a las tarjetas (no hay lado propio para atribuir el pick). Un
fallo de red o un rechazo del motor se muestra en un mensaje de error breve junto a las tarjetas
-- mismo criterio que `ManualEntryPanel`/`DraftFeedbackBox`, nunca un fallo silencioso.

## Fuera de alcance
- Banear directo desde una tarjeta -- solo se pidió pickear.
- Cualquier cambio a `ManualEntryPanel` en sí -- sigue existiendo para el caso "quiero un héroe
  que no está en las 3 sugerencias".
- Deshacer un pick (`pick_reverted`) desde la tarjeta.

## Aceptación
- Con un draft activo y lado propio identificado, cada tarjeta de sugerencia (primaria y las 2
  alternativas) tiene un botón "Pickear" que aplica ese pick sin pasar por "Entrada manual".
- Con `localSide: "unknown"`, las tarjetas no muestran el botón (nada que romper).
- Un fallo de red al pickear muestra un mensaje de error visible, nunca queda colgado en silencio.
- `bun test` sin regresiones, `tsc --noEmit` limpio, `bun run lint` sin errores nuevos.
