- La distinción entre `raw: null` y `applicable: false` (introducida en 1b) **se mantiene sin
  cambios**. `position_fit` solo usa `raw: null` — nunca debe renderizarse con el texto de
  "función no configurada", que es exclusivo de `hero_pool_fit`.
- Convenciones de `.claude/rules/web.md` sin excepción: TypeScript estricto, prohibido `any`,
  prohibidos los ternarios para renderizado condicional, prohibidas las funciones anónimas
  inline como props.
