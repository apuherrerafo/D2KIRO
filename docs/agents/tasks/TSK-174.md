Ejecutar la ingesta reanudable de TSK-168 hasta alcanzar 3.000 drafts profesionales, validando
duplicados, picks/bans completos, patch y diversidad antes de recompilar patrones. La ejecución
debe ocurrir solo desde un entorno con conectividad real a OpenDota; ningún fallback inventa datos.

## Primer paso

`scripts/pro/diagnose-opendota.ts` comprueba DNS y HTTPS sin escribir datos ni tocar configuración
global del sistema. La expansión queda pendiente mientras el diagnóstico sea `dns_failed` o
`http_failed`.
