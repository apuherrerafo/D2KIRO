## Especificación de `patch_meta` (peso v1: **0.25**)
- Fuente: real — OpenDota `/heroStats`.
- Cálculo: winrate del candidato en el parche actual (`state.patch`), **en el rango de MMR
  bajo/medio, no en pro**. El producto está dirigido a jugadores de nivel bajo/medio, no a pro
  players — usar el bracket correcto de `hero_patch_stats` (ver TSK-002/003), nunca el
  agregado "todos los brackets" ni el de pro.
- **Umbral**: menos de **500 partidas** en el bracket → `raw: null`, `sampleSize: 0`.
- `explanation`: frase corta, ej. "Buen winrate este parche" o similar, concreta al dato (puede
  incluir el número de winrate si ayuda a la explicación).

## Reglas duras
- Función pura, sin I/O, nunca lanza para entradas válidas.
- `raw: null` cuando el bracket no tiene suficientes partidas — nunca se sustituye por 0 ni 0.5.

## Aceptación
- Prueba con partidas por debajo de 500 en el bracket correcto → `raw: null`.
- Prueba con ≥500 partidas → `raw` numérico, `sampleSize` = partidas del bracket, `explanation`
  coherente con el dato.
- Prueba que confirma que se usa el bracket bajo/medio y no el de pro, aunque el fixture tenga
  datos de ambos.
