## Objetivo

Una recomendación posterior a la apertura distingue evidencia de composición y flexibilidad de
posición. Un héroe solo se llama flexible cuando el catálogo curado tiene más de una posición
real; el texto nombra esas posiciones y explica que mantiene abierta la composición.
