## Objetivo

Añadir una capa explícita y auditable posterior al scoring estadístico para responder a patrones
de bans Tier-1 sin contaminar las señales observadas.

## Reglas

1. Si hay al menos dos bans de flex Tier-1, penalizar flex restantes y priorizar agresores de
   early lane configurados.
2. Si están baneados dos pilares de una estrategia macro declarada, duplicar el score del tercer
   pilar disponible.
3. Si los supports de disable/save configurados están agotados en Fase 1, priorizar el último
   support de save disponible.

## Criterios de aceptación

- Cada regla tiene tests positivos, negativos y de desempate determinista.
- Las reglas nunca reintroducen héroes baneados ni sobreescriben candidatos no disponibles.
- La capa es una función pura con tablas declarativas; no usa red ni hipótesis de picks rivales.
- El override deja evidencia de qué regla se aplicó.

## Dependencias y límites

Depende de TSK-138–140. No activa `ENABLE_PRO_DRAFTER` ni modifica el motor V5.
