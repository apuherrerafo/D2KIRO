## Contexto

SPEC.md §16.10. En 9.0 `gate.ts` corría informativo (siempre exit 0). En 9.1 pasa a **bloquear el
commit** si un cambio degrada el motor por encima de la tolerancia de null-perturbation.

## Alcance

1. **`scripts/eval/gate.ts`**: sin cambios de lógica (ya soporta `--enforce`). Se **usa** con
   `--enforce`.
2. **`scripts/verify-simplicity.sh`**: en la sección del gate de commit (`VERIFY_COMMIT_GATE=1`),
   agregar un paso que corre `bun run eval` + `bun run scripts/eval/gate.ts --enforce` contra el
   `v6-measured.json` de referencia (el re-congelado por TSK-207). Falla el commit si el veredicto
   es FAIL. **Sólo en el camino de commit** (no en el PostToolUse en caliente — demasiado lento,
   mismo criterio que tsc+bun test hoy).
3. **`scripts/eval/report.ts`** (`renderReport`): agrega una columna `EvCov` por ranker
   (media de `evidenceCoverage` del Top-6) y una línea con el `GuessingIndex` medio del Top-6 de
   `v6Full`.
4. **`scripts/eval/run.ts`**: `v6-measured.json` (frozen) incluye `evidenceCoverage`/`guessingIndex`
   agregados por benchmark.
5. **QA final de 9.1**: correr `bun run eval` sobre el **fold held-out** (nunca usado para congelar
   percentiles) y verificar PASS. Anotar en `journal.md` los números finales: NDCG@5, Bad Pick
   Rate@5, EvCov, y si se cumplió el criterio de éxito (BPR@5 < 0.293).

## Criterios de aceptación

1. `gate.test.ts`: `main(["--enforce"])` con una corrida que FALLA → exit 1. Con una que PASA →
   exit 0. Sin `--enforce` → siempre exit 0 (comportamiento de 9.0 preservado para otros usos).
2. `verify-simplicity.sh` con `VERIFY_COMMIT_GATE=1`: un cambio ficticio que baja NDCG@5 más que
   `tolerance.ndcg5` → el script falla. Un cambio dentro de tolerancia → pasa.
3. El reporte de `bun run eval` muestra `EvCov` por ranker y el `GuessingIndex` medio.
4. QA held-out registrado en `journal.md` con los números.
5. `git diff --name-only`: sólo `scripts/eval/**`, `scripts/verify-simplicity.sh`,
   `eval/baselines/**`. `apps/` no aparece.
6. `(cd scripts && bun test)` + `bun test` ambos paquetes verde.
