## Contexto

Corazón de 8A: convierte la señal `counter` de "muda en ~93% de los drafts" a "vota con capa
curada (piso) + capa estadística arreglada (umbral bajo + shrinkage)". Contrato en `SPEC.md`
§14.5 (fórmula), §14.6 (constantes), §14.7 (candado de regresión). Reglas en `.claude/rules/`
("Fase 8" en `engine.md`, `testing-seams.md`) y `CLAUDE.md`.

**Depende de `TSK-183`** (`loadHeroCounters` + `CuratedCounter`) y **`TSK-184`**
(`CounterEvidence.observedWinrate`). No toca `mix.ts` (eso es `TSK-186`).

## Alcance

**`apps/engine/src/signals/counter.ts`:**

1. `counterScorer` (singleton de módulo) → **fábrica**:
   ```typescript
   export interface CounterScorerOptions {
     minGames?: number;                    // default COUNTER_MIN_GAMES; el candado pasa 200
     shrinkPriorStrength?: number | null;  // default COUNTER_SHRINK_PRIOR_STRENGTH; null -> delta crudo
   }
   export function createCounterScorer(
     curated: Map<HeroId, CuratedCounter[]>,
     options: CounterScorerOptions = {},
   ): SignalScorer;
   ```
   Mismo patrón que `createPositionFitScorer` / `createTeamSynergyScorer`.
2. Constantes (§14.6):
   ```typescript
   const M: Record<"hard" | "medium", number> = { hard: 0.12, medium: 0.06 };
   export const COUNTER_MIN_GAMES = 10;
   export const COUNTER_SHRINK_PRIOR_STRENGTH = 20;
   ```
3. `score(state, candidate, meta)` según §14.5:
   - `revealedRivals = observedDraftFacts(state).revealedEnemyPicks` (sin cambios).
   - Por cada rival `r`, **como máximo una** `c_r`:
     - **Capa curada (prioridad)**: `curated.get(candidate)` incluye `{vs:r, level}` → `c_r = -M[level]`;
       `curated.get(r)` incluye `{vs:candidate, level}` → `c_r = +M[level]`; ambos → se suman.
       Guardar los `why` para la `explanation`.
     - **Capa estadística (sólo si `r` no quedó cubierto por la curada)**:
       `rows = createRelationshipIndex(meta.matchups, minGames).counterRows(candidate, [r])`.
       Vacío → `r` no aporta. Con fila:
       `base = row.observedWinrate - row.delta`;
       `shrunkWinrate = shrinkPriorStrength === null ? row.observedWinrate : shrinkEstimate(row.observedWinrate, row.games, base, shrinkPriorStrength)`;
       `c_r = shrunkWinrate - base`  (con `null` ⇒ exactamente `row.delta`, comportamiento de hoy).
   - `contribs` = `c_r` de los rivales cubiertos. Vacío → `{ raw: null, sampleSize: 0,
     explanation: "Sin datos suficientes de enfrentamientos para este candidato", weighted: 0 }`
     (idéntico a hoy).
   - `raw = mean(contribs)`.
   - `sampleSize = Σ row.games` **sólo** de rivales resueltos por la capa estadística (la curada
     reporta 0).
   - `explanation`: contribuciones curadas → armada de los `why` (negativos primero, hasta 2;
     positivos "Le ganás a X" después). Sólo estadística → el `buildExplanation` actual.
   - `weighted: 0` siempre.
4. `shrinkEstimate` se **importa** de `apps/engine/src/pro/shrinkage.ts` (TSK-165) — no se
   reimplementa.

**`apps/engine/src/signals/counter.test.ts`** — reescritura parcial:

5. **Candado de regresión aislado** (§14.7-1): `createCounterScorer(new Map(), { minGames: 200,
   shrinkPriorStrength: null })` sobre los fixtures actuales devuelve el **mismo `raw` /
   `explanation` / `sampleSize` que hoy**, número por número (incluye el fixture de deltas ≥200 y
   el de "todos bajo 200 → `raw: null`").
6. El test `"enemigos conocidos pero todos bajo 200 partidas -> raw: null"` **se reescribe**: con
   `minGames: 10` esa misma fixture (150 y 199 partidas) produce un `raw` shrunk real; el caso
   `null` se prueba con muestras `< COUNTER_MIN_GAMES`.
7. Comportamiento nuevo: hard counter curado (dirección directa → `raw` ≤ `-M.hard` promediado con
   el `why` en `explanation`; inversa → `raw` positivo); zona gris (dos candidatos con
   `observedWinrate`/`games` reales distintos sobre 30-100 partidas → `raw` no nulos y ordenados
   por ventaja real); shrinkage (12 vs 180 partidas, mismo `observedWinrate` → `|c_r|` distinto;
   `< 10` → ese rival no aporta); degradación (`curated` = `Map` vacío → cae a la capa
   estadística, cero excepción).
8. Fixtures **inline**, jamás `hero-counters.json` real (S9).
