## Contexto

SPEC.md §15.4.2, costura S15. Convierte una secuencia de 24 turnos de draft profesional en casos de
evaluación: por cada turno `is_pick`, el `DraftState` **anterior** a ese turno + el héroe que el
equipo profesional eligió. Función **pura**, sin I/O.

### Contexto de dominio (para Codex — no lee journal.md ni architecture.md)

- `DraftState` vive en `apps/engine/src/draft/reducer.ts`: campos relevantes `sessionId`, `schema:
  "draft-state/v1"`, `format`, `patch`, `localSide: "radiant"|"dire"|"unknown"`, `phase`, `banned:
  HeroId[]`, `picks: {radiant: HeroId[], dire: HeroId[]}`, `lastSeq`, `quality: {unconfirmed:
  HeroId[], captureStatus}`. Importar el tipo, no redefinirlo.
- `DraftDecisionContext` (`apps/engine/src/drafter/decision-context.ts`): unión
  `"team_opening"|"blind_second_pick"|"response_pick"|"closing_pick"`. Reusar `deriveDecisionContext(state, teamOpening)`.
- Esquema de `pro_draft_turns` (`scripts/pro/schema.sql`): `draft_order` 0..23, `is_pick` 0|1,
  `hero_id`, `team` 0|1. `team 0` = Radiant, `team 1` = Dire. `winning_side` vive en `pro_drafts`.

## Alcance

```ts
interface ProDraftTurn { order: number; isPick: boolean; hero: HeroId; team: 0 | 1 }
interface ReplayMeta  { matchId: string; leagueId: number; tier: "premium"|"professional"|"unknown"; patch: string }
interface ReplayCase {
  matchId: string; leagueId: number; tier: ReplayMeta["tier"];
  turnIndex: number; state: DraftState; side: "radiant"|"dire";
  actualHero: HeroId; action: "pick"|"ban"; decisionContext: DraftDecisionContext;
}
function buildReplayCases(turns: ProDraftTurn[], meta: ReplayMeta): ReplayCase[]
```

- `state.localSide` = equipo que actúa en `turnIndex` (`team 0` → `"radiant"`, `team 1` → `"dire"`).
- `state.banned` / `state.picks` = **exactamente** el prefijo `turns[0 .. turnIndex)` clasificado
  por `isPick` y `team`. **Ningún turno ≥ turnIndex puede aparecer.**
- `state.format = "captains_mode"`, `phase = "active"`, `quality = {unconfirmed: [], captureStatus:
  "ok"}`, `lastSeq = turnIndex`, `patch = meta.patch`, `sessionId = meta.matchId`.
- 9.0 devuelve `ReplayCase` **sólo para turnos `isPick === true`** (los bans alimentan
  `state.banned` pero no son objetivo).
- Shape inválido → **descartar el draft entero** con un motivo devuelto por un canal aparte
  (`{ cases: ReplayCase[]; skipped: {matchId, reason}[] }`), nunca reparar. Inválido =
  `turns.length !== 24`, héroe repetido en picks, `team` fuera de `{0,1}`, `order` no 0..23 único.

## Criterios de aceptación

1. **Prueba de no-fuga (obligatoria)**: para un fixture de 24 turnos, cada `ReplayCase` cumple que
   ningún héroe de `turns[turnIndex .. 24)` aparece en `state.banned`/`state.picks`.
2. Un fixture con `team 1` actuando → `state.localSide === "dire"`, `state.picks.radiant` contiene
   sólo los picks previos de `team 0`.
3. `decisionContext` coincide con `deriveDecisionContext` para estados de apertura, respuesta y
   cierre (3 casos).
4. Fixture con 23 turnos → 0 casos, 1 entrada en `skipped` con motivo.
5. `bunx tsc --noEmit` limpio. **Ninguna prueba abre `pro-drafts.sqlite`** — `ProDraftTurn[]`
   inline.
