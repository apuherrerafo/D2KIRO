# /brainstorm — Brainstorming

## PROPÓSITO
Explorar todas las posibilidades sin restricciones.

## REGLAS
- Pregunta: "¿Qué funcionalidades sueñas para este proyecto?"
- Guarda todo en `docs/agents/BRAINSTORM.md` (viñetas simples).
- No filtres, no critiques, no priorices.
- Cuando el usuario diga "basta", pasa el control a `/grill-me`.

## OUTPUT
Archivo `BRAINSTORM.md` con todas las ideas capturadas.

## LÍMITES
- No descartes ninguna idea.
- No escribas código.
