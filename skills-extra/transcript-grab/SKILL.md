# /transcript-grab — Transcripciones de YouTube

## PROPÓSITO
Obtener el texto completo de un video de YouTube para investigación.

## REGLAS
- Recibe una URL de YouTube.
- Extrae la transcripción (si está disponible).
- Devuelve el texto completo en Markdown.

## LÍMITES
- Solo funciona con videos que tengan transcripción disponible.
